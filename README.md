# Yandex Docs Search

ИИ-агент для поиска по RAG-базам документации, созданным на моделях векторизации Yandex Text Embeddings. Приложение
автоматически обнаруживает доступные базы в папке `data/` и показывает
только те, что реально установлены. Дефолтная установка содержит базу с документацией Yandex AI Studio.

## Возможности

- **Векторный поиск** - косинусная близость по эмбеддингам `text-search-doc`
  (256d), векторы документов из SQLite (`use_db_vectors`).
- **Итеративный поиск через function calling** - LLM сама формирует поисковые
  запросы (`search_rag`), накапливает полезные фрагменты через
  `keep_chunk_ids` и отвечает с цитатами `[#id]` (до 10 итераций,
  настраивается 1-10).
- **Настраиваемая модель** - список моделей из справочника Yandex AI Studio
  (DeepSeek V4 Flash, YandexGPT 5, Alice AI LLM, Qwen3, gpt-oss и др.),
  уровень рассуждений зависит от модели.
- **Автоопределение баз** - приложение сканирует папку `data/` и
  показывает в интерфейсе только доступные базы.
- **Streamlit UI** - sidebar-меню «Новый запрос» / «Настройки», живой
  прогресс итераций, экспорт ответа (Markdown / копирование), светлая
  тема.

## Как это работает

1. Пользователь задаёт вопрос в интерфейсе.
2. `IterativeSearch` отправляет вопрос LLM вместе с описанием инструмента
   `search_rag`.
3. LLM решает, какой поисковый запрос сформировать, и возвращает вызов
   функции.
4. Система выполняет векторный поиск по выбранной базе
   (`Retriever.search_vector`) и возвращает до `top_n` фрагментов с
   индексами `#id`.
5. LLM либо формулирует ответ с цитатами `[#id]`, либо вызывает `search_rag`
   снова, указывая `keep_chunk_ids` - какие из показанных фрагментов
   сохранить в контексте.
6. Цикл повторяется до `max_iterations` (по умолчанию 7), накапливая
   полезные фрагменты.
7. Если на последней итерации LLM снова запросила поиск, система выполняет
   его, добавляет новую партию фрагментов к накопленным и принудительно
   просит модель сформировать итоговый ответ без инструментов (модель
   получает явное сообщение, что это последняя итерация).
8. Если LLM не дала ответ (например, сбой API), используется fallback:
   финальный ответ по накопленным фрагментам без инструментов. Перед
   генерацией fallback-ответа фрагменты ранжируются по максимальному скору
   релевантности, и в промпт попадают лучшие `max_chunks`.

## Установка

Скачать с GitHub:

```bash
git clone https://github.com/TVD2100/yandex-rag-search.git
cd yandex-rag-search
```

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
```

Требуются переменные окружения:
- `SAGAAI_YANDEXAI_KEY` - API-ключ Yandex AI Studio
- `SAGAAI_YANDEXAI_KEY2` - Folder ID

## Запуск

```bash
streamlit run app.py
```

## Добавление своей базы

Приложение ищет базы в папке `data/`: каждая база - это подпапка
`data/<имя_базы>/index.db` (SQLite). Чтобы добавить новую базу:

1. Создайте папку `data/<имя_базы>/` (например, `data/my_docs/`).
2. Положите в неё файл `index.db` - SQLite-базу с таблицей `chunks`
   (колонки `id`, `text`, `source`, `chunk_index`) и таблицей `embeddings`
   (колонки `chunk_id`, `vector`) для хранения векторов документов.
3. Перезапустите приложение - база появится в списке «Поиск по
   документации».

Название базы в интерфейсе берётся из `BASE_LABELS` в `app.py`; для
неизвестных имён используется читаемое название из имени папки.

### Формат базы

```sql
CREATE TABLE chunks (
    id INTEGER PRIMARY KEY,
    text TEXT NOT NULL,
    source TEXT,
    chunk_index INTEGER
);

CREATE TABLE embeddings (
    chunk_id INTEGER PRIMARY KEY,
    vector BLOB NOT NULL  -- float32[256], сырые байты
);
```

Векторы документов должны быть построены моделью `text-search-doc` (256
измерений). Если таблица `embeddings` отсутствует, вы можете построить
векторы программно через `Retriever.build_index()` (см. `src/retriever.py`).

## Настройки

Настройки хранятся в `~/.yaagent_search_settings.json` и редактируются в
интерфейсе (страница «Настройки»): база документации, модель, уровень
рассуждений, число итераций (1-10), фрагментов на запрос (3-20), максимум
фрагментов в контексте (3-20, по умолчанию 15), температура (0.0-1.0),
максимум токенов ответа (500-10000, по умолчанию 10000), показ служебной
информации. На странице «Настройки» также есть инструкция по заданию
переменных окружения для ключей Yandex AI Studio.

## Структура

- `ARCHITECTURE.md` - описание архитектуры (слои, поток запроса, данные)
- `app.py` - Streamlit UI (автоопределение баз, форма настроек, прогресс)
- `src/` - модули поиска и генерации:
  - `retriever.py` - векторный поиск по эмбеддингам
  - `iterative_search.py` - итеративный RAG-цикл через function calling
  - `answerer.py` - генерация ответа с цитатами (fallback-путь)
  - `db.py` - доступ к SQLite (chunks + embeddings)
  - `embeddings.py` - клиент эмбеддингов Yandex AI Studio с кешем
  - `settings.py` - настройки пользователя
- `data/rag_base/` - пример базы документации (index.db)

## Кеширование

- Векторы документов: из таблицы `embeddings` в SQLite (рекомендуется для
  больших баз) или из npz-кеша (`rag/embeddings.npz`).
- Векторы запросов: JSON-кеш `rag/query_cache.json` (ключ - MD5 текста
  запроса), экономит вызовы API эмбеддингов.
